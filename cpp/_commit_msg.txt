TOO_OLD_JAVA 动态 Java 版本建议（适配新版 MC 26.2 需要 Java 25）

用户反馈：26.2 已需要 Java 25，但崩溃分析建议仍写死 Java 17/21。

根因：TOO_OLD_JAVA 规则正则捕获 class file version（如 69.0），
但 suggestion 是静态文案，未用捕获值。

修复：analyzeCrash 命中 TOO_OLD_JAVA 时，从错误文本提取 class file
version（69.0），按 needJava = classVer - 44 换算（55→11, 61→17,
65→21, 69→25），动态生成建议并替换写死文案。

验证：临时工程模拟 26.2 场景（class 69.0 vs 61.0），建议含 Java 25 PASS。
