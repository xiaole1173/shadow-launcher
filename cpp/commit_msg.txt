fix: 4个小bug集中修复

Bug 1 - InstallPage点击下载卡顿:
  QML: 先调用 navigateToProgress() 再 Qt.callLater 启动下载，
  避免主线程 I/O 阻塞导致 UI 不立即跳转。

Bug 2 - Java下载爆进度+文件损坏:
  FileDownloader: 线程分裂后，原线程的 in-flight HTTP 请求仍会返回
  完整文件数据，导致分段文件重叠、合并后损坏。新增数据截断逻辑：
  写入前检查 data.size() 是否超出当前线程的 range 范围，超标则截断。

Bug 3 - 外置登录服务器设置UI重叠:
  HomePage: 移除内联多角色选择 ListView（与角色弹窗按钮功能重复）；
  修正角色按钮 enabled/cursorShape 逻辑；服务器面板加 z:1。

Bug 4 - 文件选择器默认路径:
  三个DetailPage: fileDialog currentFolder 改为 gameDir + /versions。
