[fix] 原版隐藏 Mods 按钮改白名单判定（对齐版本选择 getBlockIcon）+ 移除 config 文件夹按钮

用户反馈：原版版本（26.2）概览仍显示 Mod 文件夹/光影包按钮；质疑 config 文件夹按钮。

根因：黑名单比较"原版"字面值不可靠——loaderType 的任何变体
（翻译/字段缺失/其他值）都会误判为加载器版。

修复（用户指路：借用版本选择列表 getBlockIcon 的检测）：
- 白名单判定：loaderType ∈ {Forge, Fabric, NeoForge, Quilt} 才算加载器版，
  其余一律原版隐藏——与图标检测语义完全一致，天然免疫变体
- 概览 _isModded + sidebar Mod 管理分区（function/height/visible 三处）统一白名单

移除 config 文件夹按钮：
- config 是加载器配置文件目录（{游戏目录}/config/），仅加载器版存在；
  且原按钮调 openConfigFolder() 实际打开的是 .minecraft 根目录（名不副实，stub）
- 需要 config 时可从"版本文件夹"进入，故移除
